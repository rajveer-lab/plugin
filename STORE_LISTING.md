## Detailed Store Description

**Stop AI Hallucinations in Real-Time.**

Hallucination Guard is an on-device, privacy-preserving Chrome extension that automatically fact-checks responses generated by **ChatGPT (chatgpt.com)**, **Claude (claude.ai)**, and **Gemini (gemini.google.com)**.

When AI models fabricate facts, swap historical dates, invent metrics, or generate dead citations, Hallucination Guard flags them instantly directly on your chat screen.

---

### Key Features

1. **Instant Answer Fact-Checking & Color-Coded Highlighting:**
   - **Supported (Green):** Factual assertions verified against trusted sources.
   - **Contradicted (Red):** Direct conflicts, numerical mismatches, or date errors.
   - **Unverified (Amber Dotted):** Statements lacking corroborating evidence.
   - Hover over any sentence to inspect the exact reference passage, confidence score, and verification judge.

2. **Fake & Broken Link Detection:**
   - Detects hallucinated URLs and checks whether linked pages actually substantiate the claims the AI attached them to.

3. **Prompt Booster:**
   - Adds a one-click **"🛡️ Boost Prompt"** button directly to ChatGPT, Claude, and Gemini input boxes.
   - Automatically injects strict grounding and citation constraints before you hit send.

4. **Zero-Configuration Wikipedia & Web Search:**
   - Automatically cross-references claims with Wikipedia without requiring any account or API key.
   - Optionally connect your private Brave Search API token for live web retrieval.

5. **Chrome On-Device AI Validation:**
   - Leverages Chrome's built-in **Prompt API (Gemini Nano)** to run neural claim verification directly on your GPU/NPU—completely offline.

6. **Fact Memory Ledger:**
   - Built on the reverify standard: stores tool-verified facts locally so repeated questions and assertions are validated in milliseconds.

7. **Zero False Accepts Guarantee:**
   - Every verification result adheres to strict entity, numerical, and temporal consistency. A claim is never marked supported if critical figures or named entities differ from source evidence.

---

### Privacy & Security Policy

- **100% Local Execution:** VeriGuard runs entirely in your browser.
- **No External Servers:** No chat messages, prompts, or personal data are ever uploaded to third-party servers.
- **No Analytics or Trackers:** Zero tracking, zero telemetry, zero cookies.
- **Minimal Permissions:** Only operates on active AI chat tabs and permissions you explicitly grant.

---

### Installation & Developer Setup

1. Open `chrome://extensions` in Google Chrome.
2. Enable **Developer mode** in the top right.
3. Click **Load unpacked** and select the `extension/` directory.
4. Open ChatGPT, Claude, or Gemini and ask any question!
